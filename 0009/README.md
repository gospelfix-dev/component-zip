# 연두 (yeondu) — 브랜드 아이덴티티

"연두"는 아직 실존 클라이언트가 확정되지 않은 플레이스홀더 뷰티샵 브랜드다. 이 문서는
구현 세부 수치가 아니라 **"이 브랜드는 왜 이렇게 보이고, 왜 이런 말투를 쓰는가"**를
정의하는 정체성 문서다 — 색·문장·심볼이 전부 하나의 이야기로 묶이도록 의도했다.

구현 토큰(정확한 px, 컴포넌트 규격)은 [`docs/`](docs/README.md)가 정본이다. 이 문서는
그 값들이 "왜 그 값인지"를 설명하는 상위 문서로 읽는다.

## 한 줄 정의

> 과하지 않은, 나에게 맞는 변화

이 한 문장이 포지셔닝이자 헤드라인이자 브랜드가 하는 모든 선택의 기준이다. "극적인
반전"이 아니라 "내 속도에 맞는 변화"를 판다 — 그래서 과장, 이모지, 반짝이는 애니메이션,
두 번째 포인트 컬러처럼 "과한" 요소는 전부 의도적으로 배제했다(아래 "하지 않는 것" 참고).

## 이름의 의미 — 왜 "연두"인가

브랜드명은 포인트 컬러에서 그대로 따왔다. `lime`(`#EFF382`)은 국문 색이름으로
**연두색**이고, 연두는 짙은 초록이 되기 **직전** 단계의 색이다 — 완성된 색이 아니라
"서서히 짙어지는 중"인 색이다.

- 색을 먼저 정하고 이름을 붙인 게 아니라, 색의 **성질**이 "과하지 않은, 나에게 맞는
  변화"라는 기존 포지셔닝과 저절로 맞아떨어졌다. 억지로 갖다 붙인 은유가 아니다.
- 실제 소개 카피에도 이 연결을 문장으로 풀어뒀다: *"짙은 초록이 되기 전 여린 새잎처럼,
  무리하지 않는 속도로 나아갑니다."* ([about.body](data/content.json))
- 이름이 곧 색이라서 "왜 이 색을 쓰냐"는 질문 자체가 필요 없다 — 이름을 말하는 것이
  곧 색을 설명하는 것이다.

## 키워드 / 톤앤매너

| 키워드 | 의미 |
| --- | --- |
| 차분함 | 서두르지 않는다. 즉각적인 효과나 드라마틱한 비포·애프터를 과시하지 않는다 |
| 정확함 | 시술 설명은 쉬운 말로, 막연한 약속 대신 구체적인 정보로 신뢰를 준다 |
| 자연스러움 | 피부 본연의 리듬을 먼저 본다. 유행보다 개인의 속도를 우선한다 |

톤은 **차분한 전문가형**이다. 존댓말, 짧은 문장, 쉬운 시술 설명. 느낌표나 이모지로
텐션을 끌어올리지 않는다. 스타일 레퍼런스는 Linear·Vercel·Notion처럼 여백이 넓고
평평한 UI — 화려함 대신 정돈됨으로 신뢰를 준다.

## 컬러

| 토큰 | HEX | 미리보기 | 브랜드적 의미 |
| --- | --- | --- | --- |
| `lime` (포인트) | `#EFF382` | 🟡🟢 | 브랜드명 그 자체. 여린 새잎·서서히 짙어지는 변화 |
| `tint` | `#F7FAC4` | 🟡 | `lime`의 가장 옅은 버전. 부담 없이 쓰는 보조 강조 |
| `limeHover` | `#E3E868` | 🟢 | `lime`이 한 톤 짙어진 상태 — 인터랙션 피드백 전용, 정체성 색은 아님 |
| `ink` | `#151515` | ⚫ | 과장 없는 단정함. 제목·본문, `lime` 위의 유일한 글자색 |
| `gray` | `#5F5F5C` | ⚪ | 보조적인 차분함. 메타 정보·캡션 |
| `surface` | `#F5F5F3` | ⚪ | 숨 쉴 여백. 카드·섹션 배경 |
| `surfaceHover` | `#ECECE9` | ⚪ | `surface`의 인터랙션 피드백 |
| `white` | `#FFFFFF` | ⚪ | 기본 배경, 깨끗함 |

**원칙은 "모노톤 + 포인트 1개"다.** 강조는 오직 `lime` 하나로만 한다 — 포인트 컬러를
2개 이상 쓰지 않는다. 그리고 `lime`은 배경(채움)으로만 쓰고 **글자색·아이콘색으로는
절대 쓰지 않는다**(흰 배경 위 `lime` 텍스트 대비는 약 1.1:1로 사실상 읽을 수 없다).
`lime`/`tint` 배경 위 글자는 예외 없이 `ink`다.

전체 사용 규칙은 [`docs/02-colors.md`](docs/02-colors.md), CSS 변수는
[`docs/09-shadcn-tokens.md`](docs/09-shadcn-tokens.md) 참고.

## 타이포그래피

폰트는 **Noto Sans KR 하나만** 쓴다(400 / 500 / 700). 장식 폰트·이탤릭은 쓰지 않는다 —
레퍼런스로 참고했던 LUMINA·Skin—clean류의 세리프 이탤릭 헤드라인은 이 브랜드의
"정돈됨"과 맞지 않아 의도적으로 배제했다. 위계는 오직 굵기와 크기로만 만든다.

| 스타일 | 크기/행간 | 굵기 | 용도 |
| --- | --- | --- | --- |
| H1 | 32/40 | 700 | 히어로 헤드라인 |
| H2 | 22/30 | 700 | 섹션 제목 |
| Body | 16/26 | 400 | 본문 |
| Button | 15/24 | 500 | 버튼 라벨 |
| Caption | 13/20 | 500 | 태그·메타 |

자세한 적용 규칙은 [`docs/03-typography.md`](docs/03-typography.md).

## 심볼 / 워드마크

현재 연두는 **일러스트 로고마크가 없다.** 소문자 `yeondu` 워드마크 하나가 아이덴티티의
전부다 — Linear·Vercel·Notion처럼 "타이포그래피 자체가 심볼"인 접근이다. 별도 아이콘을
더하는 대신 폰트 굵기·여백·컬러만으로 브랜드를 알아보게 하는 쪽을 택했다.

- 워드마크: `yeondu` (모두 소문자, Noto Sans KR 700)
- 위치: 헤더 좌측 고정, 클릭 시 히어로로 스크롤
- 파비콘·앱 아이콘: 아직 없음 — 추가 시 워드마크 대문자 "Y" 또는 아래 제안 모티프 중
  하나로 결정할 것

**미구현 제안(옵션)**: 브랜드 서사가 "짙어지기 전의 여린 새잎"이므로, 향후 별도
심볼이 필요해지면 **외잎 하나(싹/새잎 실루엣)**를 단색 `ink` 라인으로 그린 미니멀
모티프를 제안한다. 다만 이는 결정된 사양이 아니라 제안일 뿐이다 — 실제로 추가하기
전에는 구현하지 않는다(이 프로젝트는 사진도 실사 없이 플레이스홀더만 쓰는 원칙과 같은
맥락: 확정되지 않은 것을 임의로 만들어 넣지 않는다).

## 핵심 카피 (실제 사용 문구)

브랜드 보이스를 가장 잘 보여주는 실제 문구들이다. 전부 `data/content.json`에서
가져왔다 — 카피를 바꿀 때는 이 파일을 고치고, 아래 목록도 함께 갱신한다.

- **헤드라인**: "과하지 않은, 나에게 맞는 변화"
- **히어로 설명**: "연두는 피부 본연의 리듬을 살피는 차분한 뷰티샵입니다. 처음
  상담부터 관리까지, 나에게 맞는 속도로 안내해 드립니다."
- **소개 리드**: "피부를 대하는 방식은 늘 같습니다."
- **소개 본문**: "연두는 유행보다 **피부 본연의 리듬**을 먼저 살핍니다. 짙은 초록이
  되기 전 여린 새잎처럼, 무리하지 않는 속도로 나아갑니다. 상담부터 관리까지
  과정마다 차분하게 설명해 드리고, 꼭 필요한 관리만 권해 드립니다."
- **챗봇 인사**: "안녕하세요, 연두입니다." / "아래 질문 중 궁금하신 걸 눌러보세요."
- **버튼 라벨**: "예약하기" / "메뉴 보기" / "문의" — 전부 동사형, 군더더기 없음

**글쓰기 원칙**
- 존댓말, 짧은 문장
- 시술 설명은 쉬운 말로 (전문 용어로 위압감을 주지 않는다)
- "최고", "100% 만족" 같은 과장 표현을 쓰지 않는다
- 확인되지 않은 후기·수치·수상 내역을 지어내지 않는다 — 없으면 자리표시로 남긴다

## 모션 — 절제된 변화

브랜드 메시지("과하지 않은 변화")는 모션에도 그대로 적용된다.

- 전환은 `transform`/`opacity`만, 0.2초 이하의 짧은 페이드
- 패럴랙스, 큰 이동, **무한 반복 애니메이션 없음**
- 스크롤 리빌은 전부 1회성(`IntersectionObserver` 후 `unobserve`)

자세한 규칙은 [`docs/01-style-reference.md`](docs/01-style-reference.md)의 모션 원칙,
구현은 [`.claude/rules/02-css.md`](.claude/rules/02-css.md) 참고.

## 레이아웃 — 플랫

`border`와 `box-shadow`를 쓰지 않는다. 레이어 구분은 오직 **배경색 차이**(`white` ↔
`surface`)로만 한다 — 입체감 대신 여백과 색 대비로 정보 위계를 만든다. 모서리는
버튼·카드·이미지 6px, 태그만 완전 둥글게(16px 이상)인 2단 체계만 쓴다.

## 이 브랜드가 하지 않는 것

정체성은 무엇을 하는가 만큼 **무엇을 하지 않는가**로도 정의된다.

- 포인트 컬러를 2개 이상 쓰지 않는다
- 그라데이션, 그림자, 테두리 카드를 쓰지 않는다
- 장식 폰트, 이탤릭, 이모지 아이콘을 쓰지 않는다
- 무한 반복 애니메이션을 쓰지 않는다
- 확인되지 않은 후기·수치·수상 내역을 만들지 않는다
- "최고", "100% 만족" 같은 과장 표현을 쓰지 않는다
- 스톡 사진을 쓰지 않는다 — 실사진이 없으면 `tint`/`surface` 배경 + `[이미지 설명]`
  자리표시로 둔다 (초상권·라이선스 문제를 피하기 위함)

## 레퍼런스와의 관계

디자인 레퍼런스로 blissful(화장품 커머스)·LUMINA(스킨클리닉)·Skin—clean(코스메톨로지
클리닉) 3곳을 참고했지만, **업종도 다르고 톤도 다르다.** 섹션 구성·레이아웃 패턴
(카테고리 탭, 갤러리 그리드, 3열 푸터 등)만 빌렸을 뿐, 색·타이포·모션은 전부 연두의
독자 체계를 따른다 — 레퍼런스의 세리프 이탤릭 헤드라인이나 그림자·글래스모피즘 같은
요소는 이 문서의 "하지 않는 것"과 충돌해 가져오지 않았다.
