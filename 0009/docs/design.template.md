# design.template.md — 새 프로젝트용 빈 템플릿

`DESIGN.md`와 같은 구조를 다른 샵/프로젝트에 재사용할 때 복사해서 채우는 틀입니다.
`[대괄호]`는 반드시 실제 값으로 채우고, 값이 없으면 지어내지 말고 `[대괄호]`로 남겨
둡니다. `(제안)`이 붙은 항목은 보드 확정값이 아니므로 필요시 조정 가능합니다.

## 2. 컬러 (모노톤 + 포인트 1개)

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `ink` | `[#000000]` | 제목, 본문 |
| `gray` | `[#000000]` | 보조 텍스트, 캡션 |
| `surface` | `[#000000]` | 섹션·카드 배경, 보조 버튼 |
| `accent` (포인트) | `[#000000]` | CTA 버튼, 강조 텍스트 |
| `tint` | `[#000000]` | 태그, 선택·강조 배경 |
| `white` | `#FFFFFF` | 기본 배경 |
| `accentHover` | `[#000000]` | CTA 버튼 hover |
| `surfaceHover` | `[#000000]` | 보조 버튼 hover |

- 본문 크기 텍스트 기준 대비 4.5:1 이상을 유지합니다(배포 전 도구로 확인).

## 11. 에이전트 작업 규칙

1. 색, 간격, 글자 크기는 토큰만 씁니다. 새 값이 필요하면 질문합니다.
2. 실제 데이터(상호, 가격, 후기, 주소)는 받은 값만 씁니다. 없으면 `[대괄호]`로 남깁니다.
3. 반복 요소는 컴포넌트로 만들어 재사용합니다.
4. 모바일 기준 폭에서 먼저 완성하고 가로 스크롤을 만들지 않습니다.
5. 아이콘 버튼에는 `aria-label`을 달고, 클릭 요소는 `button`/`a`를 씁니다.
