# 02. 컬러

`DESIGN.md` "2. 컬러 (모노톤 + 포인트 1개)" 섹션에서 옮겨왔습니다.

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `ink` | `#151515` | 제목, 본문 |
| `gray` | `#5F5F5C` | 보조 텍스트, 캡션 |
| `surface` | `#F5F5F3` | 섹션·카드 배경, 보조 버튼 |
| `lime` (포인트) | `#EFF382` | 예약 버튼 등 채움(fill) 강조. 글자색으로는 쓰지 않음 |
| `tint` | `#F7FAC4` | 태그, 선택·강조 배경, 이미지 자리표시 |
| `white` | `#FFFFFF` | 기본 배경 |
| `limeHover` | `#E3E868` | 예약 버튼 hover |
| `surfaceHover` | `#ECECE9` | 보조 버튼 hover |

## 사용 규칙

- 포인트 컬러는 `lime` 하나만 씁니다. 다른 강조색을 추가하지 않습니다.
- **`lime`은 밝은 색이라 글자색·아이콘색으로 쓰지 않습니다.** `lime` 위 글자는 반드시
  `ink`입니다(흰 배경 위 `lime` 대비는 약 1.1:1이라 텍스트로 쓰면 읽을 수 없습니다).
- 대비(직접 계산한 근사값, 배포 전 도구로 재확인 권장): `lime` 위 `ink` 약 16:1. 본문
  크기 텍스트 기준 4.5:1 이상을 유지합니다.
- 연한 `gray` 계열을 흰색 위 작은 글씨에 쓰지 않습니다.

실제 구현용 CSS 변수/테마 값은 [09-shadcn-tokens.md](09-shadcn-tokens.md)를 참고하세요.
