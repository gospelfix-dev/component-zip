# 01. 스타일 레퍼런스

`DESIGN.md` "1. 아이덴티티" + "7. 모션" 섹션에서 옮겨왔습니다.

## 아이덴티티

| 항목 | 내용 |
| --- | --- |
| 포지셔닝 | [누구를 위해] 과하지 않은, 나에게 맞는 변화를 [어떻게] 만드는 [지역] 뷰티샵 |
| 키워드 | 차분함 · 정확함 · 자연스러움 |
| 톤앤매너 | 차분한 전문가형. 존댓말, 짧은 문장, 과장 표현 금지, 시술 설명은 쉬운 말로 |
| 대표 헤드라인(시안) | 과하지 않은, 나에게 맞는 변화 |
| 스타일 레퍼런스 | Linear, Vercel, Notion처럼 여백이 넓고 평평한 UI |

`[대괄호]`로 남은 포지셔닝 문장은 샵별로 채울 자리표시입니다. 임의로 지역명이나
타깃을 지어 넣지 않습니다.

## 모션 원칙

- 전환은 0.2초 이하이며 색 변화나 페이드만 씁니다 (시안은 `background-color 0.15s`).
  모션 자체가 없어도 무방합니다.
- 패럴랙스, 큰 이동, 반복 애니메이션은 쓰지 않습니다.

여백이 넓고 평평한 Linear/Vercel/Notion 계열의 차분한 톤을 유지하는 것이 이 스타일
레퍼런스의 핵심이며, 아래 02~09 파일의 모든 토큰은 이 톤을 벗어나지 않는 범위에서
정해졌습니다.
