## 레이아웃 (모바일 우선)

- 기준 폭은 390px, 좌우 여백 20px입니다. 데스크톱은 콘텐츠 폭을 제한하고 가운데
  정렬합니다 (제안).
- 섹션 순서와 배경색:

| 순서 | 섹션 | 배경 |
| --- | --- | --- |
| 1 | 헤더 | `white` |
| 2 | 히어로 (헤드라인, 설명, 예약·문의 버튼, 대표 이미지) | `surface` |
| 3 | 시그니처 메뉴 | `white` |
| 4 | 전후 사진 | `surface` |
| 5 | 디자이너·원장 소개 | `white` |
| 6 | 실제 후기 | `white` |
| 7 | 가격·위치·영업시간 | `white` |
| 8 | 푸터 (상호, 대표자, 사업자등록번호, 주소, 연락처) | `surface` |

- 하단 고정 바와 챗봇 버튼은 모든 섹션 위에 떠 있으며, 푸터 아래쪽 여백을 72px
  확보해 가리지 않게 합니다.
- 섹션 안쪽 여백은 상하 24 / 좌우 20, 섹션 제목과 내용 간격은 16입니다
  ([04-spacing.md](04-spacing.md) 참고).

## 이미지

- 같은 조명, 같은 구도, 자연광을 씁니다. 과한 보정은 금지입니다.
- 전후 사진은 같은 각도·같은 거리에서 촬영한 실제 사진만 씁니다. 실제 후기와 사진이
  없으면 해당 섹션은 비워 두고 만들어 넣지 않습니다.
- 사진이 아직 없을 때는 `tint` 또는 `surface` 배경에 `[이미지 설명]` 자리표시를 둡니다.

## 하지 말 것

- 포인트 컬러를 2개 이상 쓰기, 그라데이션, 그림자, 테두리 카드
- 장식 폰트, 이모지 아이콘
- 확인되지 않은 후기·수치·수상 내역 만들기 (자리표시로 둡니다)
- 과장 표현 ("최고", "100% 만족" 등)

## 에이전트 작업 규칙

1. 색, 간격, 글자 크기는 토큰만 씁니다. 새 값이 필요하면 임의로 추가하지 말고 질문합니다.
2. 샵 정보(상호, 시술명, 가격, 후기, 주소)는 받은 값만 씁니다. 없으면 `[대괄호]`
   자리표시로 남깁니다.
3. 버튼, 태그, 카드는 컴포넌트로 만들어 재사용합니다.
4. 모바일 390px에서 먼저 완성하고, 가로 스크롤이 생기지 않게 합니다.
5. 아이콘 버튼에는 `aria-label`을 달고, 클릭 요소는 `button` 또는 `a`를 씁니다.
