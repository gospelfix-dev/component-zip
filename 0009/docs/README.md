# docs/ 안내

이 디렉터리는 "뷰티샵 브랜딩 랜딩페이지" 디자인 규칙을 주제별로 쪼갠 문서 모음입니다.
각 수치·토큰은 **해당 주제를 다루는 파일 하나에만** 있습니다 — 다른 파일이나
`DESIGN.md`에 같은 내용을 중복해서 적어두지 않습니다. `DESIGN.md`는 내용을 담지 않고
아래와 같은 목차 역할만 합니다.

- 표기: `[대괄호]`는 샵별로 채울 자리표시, `(제안)`은 원본 보드에는 없고 구현 편의를 위해
  덧붙인 권장값입니다.
