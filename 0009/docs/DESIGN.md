# DESIGN.md — 뷰티샵 브랜딩 랜딩페이지

"02 아이덴티티와 스타일 가이드" 보드와 "03 디자인 적용 시안"을 기준으로 정리한 디자인
규칙입니다. AI 코딩 에이전트와 디자이너가 같은 기준으로 화면을 만들 수 있도록 쓰는
문서이며, 실제 내용은 아래 파일들로 나뉘어 있습니다 — 이 파일은 목차 역할만 합니다.

- 표기: `[대괄호]`는 샵별로 채울 자리표시입니다. 임의로 문구나 수치를 만들어 넣지 않습니다.
- `(제안)` 표시는 보드에는 없고 구현을 위해 덧붙인 권장값입니다. 나머지는 보드 값 그대로입니다.
- 값이 파일 간에 어긋나면 각 주제를 다루는 아래 파일이 우선합니다(중복 보관하지 않습니다).
