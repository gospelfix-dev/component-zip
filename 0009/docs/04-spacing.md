# 04. 간격

`DESIGN.md` "4. 간격·모서리" 중 간격 부분에서 옮겨왔습니다. 모서리 규격은
[05-radius.md](05-radius.md)를 참고하세요.

- 간격은 4pt 기준이며 `8 · 12 · 16 · 24 · 48`만 씁니다. 섹션 여백은 넉넉하게 둡니다.
- 터치 영역은 최소 44px입니다.
- 섹션 안쪽 여백은 상하 24 / 좌우 20, 섹션 제목과 내용 간격은 16입니다
  (자세한 섹션 배치는 [08-guidelines.md](08-guidelines.md)의 레이아웃 참고).

## 스케일 토큰

| 토큰 | 값 |
| --- | --- |
| `space-1` | 8px |
| `space-2` | 12px |
| `space-3` | 16px |
| `space-4` | 24px |
| `space-6` | 48px |

구현용 CSS 변수는 [09-shadcn-tokens.md](09-shadcn-tokens.md)를 참고하세요.
