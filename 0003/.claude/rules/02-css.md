# CSS 규칙

## 파일 순서

`css/style.css` 는 이 순서를 유지한다. 새 스타일은 해당 구획 안에 넣는다.

1. `:root` 토큰 (색상 → 타이포 → 간격/모양)
2. 리셋 / `body`
3. 배경 장식
4. 페이지 레이아웃
5. 카드 그리드
6. 카드 컴포넌트
7. 미디어 영역
8. 상태 (로딩/에러)
9. 반응형 미디어쿼리
10. `prefers-reduced-motion`

## 명명

BEM 을 따른다: `블록__요소--수식어`

```
.palette-card
.palette-card__name
.palette-card__media
```

블록 이름을 바꿀 때는 `index.html` 의 `<template>`, `js/app.js` 의 `querySelector`,
`css/style.css` 를 **동시에** 수정한다. 한 곳만 바꾸면 카드가 렌더링되지 않는다.

## 값 작성

- **색상은 반드시 `:root` 토큰을 쓴다.** 컴포넌트 안에 하드코딩한 헥사값을 넣지 않는다.
  새 색이 필요하면 토큰을 먼저 추가한다.
- **크기는 `clamp()` 로 반응형 처리한다.** 미디어쿼리로 폰트 크기를 계단식 변경하지 않는다.
  `clamp(최소, 유동, 최대)` — 유동값은 `vw` 기준.
- 인라인 SVG 안에서도 `fill="var(--c-card, #fdfbf7)"` 처럼 토큰을 참조할 수 있다. 폴백값을 함께 적는다.

## 애니메이션

- 전환은 `transform` 과 `opacity` 만 쓴다. `width`/`height`/`top` 을 전환하지 않는다.
- 이징은 `cubic-bezier(0.22, 1, 0.36, 1)` 로 통일한다.
- **새 애니메이션을 추가하면 `prefers-reduced-motion` 블록에도 반드시 예외를 추가한다.**

## 반응형 분기점

| 기본 | 3열 |
