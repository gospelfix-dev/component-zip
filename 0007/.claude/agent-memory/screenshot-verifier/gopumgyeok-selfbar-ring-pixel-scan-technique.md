02 메뉴 섹션 `#selfbarGrid` 의 원형 카드(`.sb-item .circle`)는 CSS `border` 가 아니라 **각 jpg
이미지 자체에 구운 흰 여백**이 `border-radius:50%` 클리핑을 통해 링처럼 보이는 구조다(CSS 링이
아님). 그래서 "링이 얇아 보인다"는 피드백은 CSS 문제가 아니라 사진마다 원본 촬영 여백이 달라서
생긴다.

육안 비교(스크린샷 리사이즈 크롭)만으로는 카드마다 배경(하얀 사기그릇 vs 갈색 나무 접시 vs
회색 톤)이 섞여 있어 "링"과 "그릇 안쪽 밝은 부분"이 눈으로 잘 구별되지 않는다. 실측하려면
풀페이지 스크린샷을 찍은 뒤 PIL 로 각 원의 가로 중심선(scanline)을 따라 픽셀을 순회하며, 검정
배경(RGB 전부 <25) → 거의 순백(RGB 전부 >250) → 그 외 색(그릇/식재료)로 전이되는 지점을 찾아
백색 구간 길이(px)를 측정하면 카드 간 링 두께를 숫자로 비교할 수 있다. 순백 임계값을 235~250 정도로
엄격하게 잡아야 그릇 안쪽의 오프화이트(예: 깻잎 카드의 흰 사기그릇, 220~230대)와 진짜 바깥
여백을 구별할 수 있다 — 느슨한 임계값(>200)을 쓰면 그릇 내부까지 링으로 오판한다.

**Why:** 2026-09-16, kale/kkaennip/yeongeun 3장을 180x180 캔버스에 154x154로 축소 후 중앙
배치(사방 13px 흰 여백)해 다른 5장과 통일시켰는지 검증할 때, 이 스캔 방식으로 8개 카드 모두
순백 구간이 약 7~8px(1440px 폭 풀페이지 렌더 기준, 원 지름 약 120px일 때)로 일치함을 확인했다.
kkaennip 카드는 흰 사기그릇이 배경이라 순백 구간이 두 단계(바깥 링 7px + 안쪽 그릇 밝기)로
이어져 육안 크롭만으로는 훨씬 두꺼워 보였지만, 픽셀 값 분석으로 실제 바깥 링은 동일하다고 확인됐다.

**How to apply:** 셀프바(또는 유사한 원형 클리핑 이미지) 카드 여러 장의 여백/링 두께 일관성을
검증할 때, 먼저 육안 크롭으로 대략 훑고 의심되는 카드가 있으면 이 스캔라인 픽셀 측정으로
재확인한다. 큰 프로그래매틱 스크롤은 [[headless-large-scroll-screenshot-black-frame]] 때문에
피하고, 대신 `.hero{position:relative;min-height:auto}` 오버라이드만 주입한 디버그 사본을
`--window-size` 높이를 넉넉히(예: 4700px) 잡아 풀페이지로 찍은 뒤 필요한 섹션만 크롭해서 쓴다.
