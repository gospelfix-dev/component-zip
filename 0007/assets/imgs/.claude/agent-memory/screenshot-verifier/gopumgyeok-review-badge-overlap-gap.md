2026-09-08 경, 사용자가 `.review-badge` 를 폰 목업 위에 여백 없이 겹치도록
(`margin-bottom:-26px; position:relative; z-index:3`) 수정한 뒤 검증 요청. 스크린샷 실측 결과
**여전히 배지 하단과 폰 프레임 상단 사이에 눈에 띄는 빈 틈이 남아 있었다** — 의도한 "겹쳐 붙는"
효과가 나지 않았다.

**실측(1440px 데스크톱, 3열 그리드 중앙 카드 기준, 스크린샷 픽셀 = CSS px 1:1)**:
- 배지(`--red` #A6291F, RGB 166,41,31) 순수 영역: y 약 4006~4080
- 배지 하단부터 폰 프레임(회색 베젤) 상단까지 배경색만 있는 빈 구간: 약 44px
  (다른 x 컬럼에서도 35~45px 범위로 일관됨)
- 즉 `margin-bottom:-26px` 를 적용해도 실제 겹침은커녕 40px 안팎의 갭이 남는다 —
  역산하면 margin 없이(0px) 자연스러운 간격이 약 60px 정도라는 뜻이고, 배지와 완전히
  맞닿게 하려면 margin-bottom 을 약 -60px, 참고 이미지처럼 노치 부분까지 살짝 파고드는
  느낌을 원하면 -75~-85px 정도까지 가야 할 가능성이 높다(사용자가 직접 반복 조정하며
  눈으로 맞추는 게 안전 — 정확한 필요값은 -26 → -60 사이 어딘가부터 시작해서 점진적으로
  늘려보는 방식을 권장했다).
- z-index 자체는 정상 동작(배지가 폰보다 위 레이어) — z-index 문제는 없었고 순전히 margin
  절대값 부족 문제였다.
- 3열 데스크톱(`max-width:1120px` wrap)에서 폰 300px × 3 + gap 32px × 2 = 964px 로 여유 있어
  카드 간 겹침/그리드 밖 넘침 없음. 1024px 경계 위(1025px)/아래(1024px) 각각 확인, 모바일
  2열 + 3번째 카드 중앙 정렬도 정상. 배지 텍스트("왕십리 본점 리뷰 675+" 등 최장 문구)는
  500px 폭까지 줄바꿈/잘림 없음 — 폭 관련 문제는 전혀 없었고 순수히 겹침(overlap) 부족만
  이슈였다.
