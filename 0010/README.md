# ASCII 3D 크리스마스 트리

글자(ASCII)만으로 그린 3D 크리스마스 트리 웹페이지입니다.
트리가 아래층부터 한 층씩 쌓이고, 장식·전구·별이 차례로 붙은 뒤 천천히 회전합니다.
눈이 내리고 하늘에서 선물 상자가 떨어지며, 배경음악으로 캐롤이 흐릅니다.

## 실행

| 방법 | 음악 자동 재생 |
|---|---|
| VS Code Live Server로 `index.html` 열기 (포트 5500) | 화면을 한 번 클릭하면 재생 |
| 터미널에서 `python3 -m http.server` 후 `http://localhost:8000` | 화면을 한 번 클릭하면 재생 |
| 아티팩트 링크 https://claude.ai/artifact/QU74eET2PagUCeT6cP9QSh | 브라우저에 따라 바로 재생되거나 첫 클릭 때 재생 |

- **아티팩트 링크**는 비공개입니다. 다른 사람에게 보여 주려면 페이지의 공유 메뉴에서 먼저 공유해야 합니다.
- `index.html`을 더블클릭해 `file://`로 열어도 트리는 동작합니다. 다만 음악 파일을 읽지 못하면 내장 오르골 캐롤로 바뀝니다.

## 조작

| 입력 | 동작 |
|---|---|
| 드래그 | 트리 회전 (휙 밀면 잠시 빠르게 돈 뒤 원래 속도로 돌아옴) |
| `M` | 음악 재생 / 일시정지 |
| `R` 또는 **다시 쌓기** 버튼 | 트리를 처음부터 다시 쌓기 |
| `Esc` | 플레이어 메뉴 닫기 |

### 음악 플레이어 (오른쪽 위)

- **▶ / ❚❚**: 재생 / 일시정지
- **◀◀ ▶▶**: 재즈 녹음은 10초씩 이동, 오르골 캐롤은 이전 곡 / 다음 곡
- **진행 바**: 드래그해서 원하는 위치로 이동
- **♡**: 좋아요 (브라우저에 기억됨)
- **🔈**: 음소거
- **⋯ 메뉴**
  - 재즈 녹음 ↔ 오르골 캐롤 전환
  - 플레이어 접기 (작은 알약 모양으로 줄어듦. 접은 상태도 기억됨)

## 주소 옵션

| 옵션 | 예시 | 설명 |
|---|---|---|
| `seed` | `index.html?seed=7` | 같은 숫자면 장식·전구·눈 배치가 매번 같음 (없으면 무작위) |
| `speed` | `index.html?speed=2` | 쌓이는 연출 속도 배수 (2 = 두 배 빠르게) |

운영체제에서 "동작 줄이기(reduced motion)"를 켜면 쌓이는 연출 없이 완성된 트리가 바로 나옵니다.
회전은 느려지고, 눈은 적게 내리며, 선물은 계속 떨어지지 않습니다.

## 파일

```
christmas_tree/
├── index.html     페이지 뼈대 (HTML)
├── style.css      화면 스타일 (트리 화면, 하단 상태 줄, 음악 플레이어)
├── script.js      트리 렌더링, 애니메이션, 음악 재생 (빌드 과정 없음)
├── carol.mp3      배경음악
└── README.md
```

외부에서 불러오는 것은 Google Fonts(IBM Plex Mono, Inter)뿐입니다. 연결이 없으면 시스템 글꼴로 대체됩니다.

## 동작 원리 (간단히)

- **3D 점 구름**: 바늘잎·가랜드·장식·전구·선물을 수만 개의 3D 점으로 만듭니다. 매 프레임 Y축으로 회전시킨 뒤 원근 투영으로 글자 격자에 찍습니다. 칸마다 가장 가까운 점만 남깁니다(z-버퍼).
- **명암 → 글자**: 빛을 받는 정도에 따라 `.,:+xX%$#` 중 하나를 고릅니다. 밝을수록 획이 많은 글자가 됩니다. 장식 공에는 하이라이트(`@`)가, 멀리 있는 점에는 안개 효과가 들어갑니다.
- **번짐 효과**: 전구, 별, 인사 문구는 캔버스 `shadowBlur`로 한 번 더 그려 빛이 번지게 합니다.
- **음악**: `carol.mp3`를 반복 재생합니다. 파일을 읽지 못하면 Web Audio로 합성한 오르골 캐롤(종소리, 패드, 썰매 방울)로 바뀝니다.
