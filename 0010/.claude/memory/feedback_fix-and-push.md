사용자가 "이게 왜 ~에서 안 돼?"라고 물으면, 원인만 설명하지 말고 직접 재현하고, 고치고, 검증하고, 커밋·푸시(GitHub Pages 반영 확인)까지 한 번에 끝낸다.

**Why:** 2026-11-19 "왜 모바일에서 제대로 실행을 못해?"라는 질문에 원인 분석, 수정, headless Chrome 검증, 푸시까지 묻지 않고 진행했다. 사용자는 반박 없이 받아들였고, 이어서 "중요한 것 모두 커밋/푸쉬해줘"라고 했다. 전역 메모리의 "질문 없이 진행"과도 맞는다.

**How to apply:**
- 재현은 실제 배포 주소 기준으로 하고, 고친 뒤에도 같은 방법으로 다시 확인한다. 방법은 CLAUDE.md의 Mobile check에 있다.
- 실제 기기에서 확인하지 못한 부분은 보고할 때 그렇다고 밝힌다.
- 이렇게 끝내는 대상은 이 저장소의 커밋·푸시까지다. claude.ai 아티팩트처럼 다른 곳에 게시하는 일은 하지 않는다. [[feedback-no-artifact]]
