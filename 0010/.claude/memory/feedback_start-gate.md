페이지를 열자마자 소리가 나게 하는 것은 브라우저 자동 재생 정책 때문에 불가능하다. 2026-11-19에 두 가지 안(① 시작 화면 ② 무음 재생 후 첫 클릭에 소리 켜기)을 제시했고, 사용자는 ① 시작 화면을 골랐다. 첫 탭에 음악과 트리 쌓기가 함께 시작된다.

시작 버튼이 로드 때 포커스를 받으면서 생긴 노란(`--gold`) 포커스 테두리를 사용자가 스크린샷과 함께 "없애줘"라고 했다. 지금은 키보드 포커스일 때 테두리만 살짝 밝아진다.

**Why:** 사용자는 "접속하자마자 음악"을 원했지만, 불가능하다는 설명을 듣고 첫 탭이 자연스러운 연출이 되는 쪽을 받아들였다. 노란 링은 의도한 장식이 아니라 오류처럼 보였다.

**How to apply:**
- 다시 "바로 재생" 요청이 오면 우회 런처나 무음 트릭을 새로 제안하지 말고, 이미 시작 화면으로 결정했음을 상기시킨다.
- 시작 화면이나 큰 유리 버튼에 금색 outline 포커스 링을 다시 넣지 않는다. 키보드 포커스 표시는 테두리 밝기 변화처럼 은은하게 한다.
